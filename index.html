About
PinScout v1.0
Searches eBay sold & active listings to estimate current market value for Disney collectible pins.

Data sourced from eBay public listings. Values are estimates based on recent sold prices and should be used as a guide only.
📷 Search by Image

Two options to identify a pin by photo:

Google Lens (recommended):
Opens Google Lens where you can take/upload a photo. It will identify the pin — copy the name, come back and paste it in the search box.

Take Photo / Library:
Takes a photo and uses the filename as a search hint. Works best if you rename the file to the pin name first.
